声织 Voice Loom 1.2 · Windows x64

双击「声织.exe」打开工作台。便携版请完整解压 ZIP 后运行。
系统要求：Windows 10/11 x64、.NET Framework 4.8、Microsoft Edge WebView2 Evergreen Runtime。
WebView2 下载：https://developer.microsoft.com/microsoft-edge/webview2/

首次使用
1. 在「设置」选择麦克风、输出设备及识别/合成服务。
2. 在「音色库」导入参考音频（建议 3～15 秒清晰干声）并选择音色。
3. 在工作台输入文字、导入录音或开启实时麦克风监听，即可按角色设定合成语音。
4. 关闭窗口会停止监听；安装后的快捷方式可重新打开。

模型
安装包包含工作台和音频处理后台。AI 模型使用独立部署的本地服务，或设置中的云端接口。
本机已部署的 G:\AI 模型可直接复用。更换电脑时按源代码 docs\BUILD.md 配置模型环境。
云端接口使用个人 API Key；系统使用当前 Windows 用户的 DPAPI 保存密钥。

数据与迁移
便携版：程序旁的 user-data 目录。安装版：%LOCALAPPDATA%\VoiceLoom。
右上角「更多工具 → 打开数据目录」可查看录音、配置、历史及字幕导出。
退出后复制整个数据目录即可备份；DPAPI 密钥在换 Windows 用户或电脑时需重新输入。
user-data\desktop.json（安装版在 %LOCALAPPDATA%\VoiceLoom）可设置 data_directory、reports_directory、port、zoom。
卸载程序保留个人数据。便携版复制时请一并复制 user-data。

显示
界面使用 Per-Monitor V2 DPI，随 Windows 缩放重新渲染。
「更多工具」中的文字大小或 Ctrl++ / Ctrl+- / Ctrl+0 可调整文字大小。

本机模型环境
「更多工具 → 本机模型服务 → 导入启动环境」可接入用户现有的 Python、启动脚本、模型程序和权重。
填写程序、工作目录、启动参数、本机端口和健康检查路径，检查通过后保存；模型连接页使用相同地址。
下方「调试」显示正在启动的模型、等待耗时、就绪状态和错误日志。启动和失败时会自动提示。

MCP
「更多工具 → 连接 AI 助手」可复制 Codex TOML 或通用 MCP JSON。
服务命令为 service\VoiceLoom.Service.exe --mcp，可通过 --data 和 --port 指定已有工作台。
AI 助手可预览、识别、生成文件、查询记录与模型服务；播放和麦克风监听使用独立操作。

字幕
「字幕输出」提供 OBS 浏览器源地址及 UTF-8 文本文件。复制带访问凭证的地址给本机 OBS 即可。
音频、API 和字幕服务监听 127.0.0.1。启动时无需打开浏览器。

诊断
「更多工具 → 诊断日志」打开日志目录。启动端口被占用时关闭旧声织后台，或修改 desktop.json 的 port。
首次运行如果 Windows 显示发布者未知，原因是当前构建没有代码签名证书。
