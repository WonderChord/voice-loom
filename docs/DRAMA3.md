# Drama3 的参考音与 LLM 表演编排

声织把台词、导演说明和声音动作分开保存，再由适配器转换为模型语法。字幕、记录正文和读音词典保持纯台词。云端 Fish `model: drama-3` 与 `drama3_local` 使用同一套编排语义；Fish S2、Breeze 和其他 TTS 按各自能力转换，不混用标签。

## 三层编排

| 意图 | 表演稿字段 | Drama3 请求中的效果 |
|---|---|---|
| 这段如何表演 | `speech.direction`，最多240字自然语言 | 句首 `[指导]`，可用中文指导日文台词 |
| 某处发出声音 | 独立 `event` | 轻笑、呼吸、惊呼等方括号事件 |
| 只改变某段词句 | `speech.delivery` | 成对 `<whisper>`、`<soft>`、`<emphasis>`、`<stress>`、`<forceful>`、`<slow>`、`<fast>` |
| 精确停顿 | 独立 `pause.duration_ms` | 本地插入相应毫秒的静音 |

`direction` 可以描述声线与吐息、角色当下神态、与听者的距离和表达目的。只写影响这一句的要素，避免互相矛盾的标签。它不需要方括号，也不能嵌入模型标签。未指定指导时仍可用 `emotion/intensity`。一段有具体指导时优先使用指导，不再叠加笼统情绪标签。

局部表演只覆盖该 speech 段；下一段选择 `normal` 恢复正常投递。数值 `speed` 调整整段语速；本地 Drama3 接口保持 `speed=1`，局部快慢可用 `slow/fast`。拟声词仅在确实属于台词时保留，不会自动重复添加笑声词或改写字幕。

```json
{
  "source_text": "欢迎回来。这句话只说给你听。我们继续吧。",
  "text": "欢迎回来。这句话只说给你听。我们继续吧。",
  "segments": [
    {"kind":"speech","text":"欢迎回来。","direction":"微笑着，像欢迎老朋友","delivery":"soft"},
    {"kind":"event","event":"breath"},
    {"kind":"speech","text":"这句话只说给你听。","direction":"靠近一些，压低声音但吐字清楚","delivery":"whisper"},
    {"kind":"pause","duration_ms":250},
    {"kind":"speech","text":"我们继续吧。","direction":"恢复自然明亮的声音","delivery":"normal"}
  ],
  "warnings":[]
}
```

“人设与提示词 → 语音表演”中的模型规则会同时提供给生成 LLM 和独立自检 LLM。生成器填结构字段；自检检查控制说明是否漏进正文，不把独立 `direction` 字段误判为台词。原文直通不主动调用 LLM；要自动编排，开启角色润色，并按需要把润色程度设为“原意保留”。关闭自动编排时也可以在记录的“编辑编排”中手动设置。

现有自定义模型规则会保留；希望使用新版规则时，在该页面点击“恢复模型默认规则”并保存。切到不支持自由指导或局部标签的备用 TTS 时会显示降级说明，只发送台词，不朗读指导或原始标签。

## 短句与作用域

默认以42字符作为 Drama3 单次请求的台词上限，优先在标点或空格处切分；这是来自中文/日文短句工作流的可调起点，并非官方模型硬限制。模型连接中可调整为15～300，0关闭；英语和长篇旁白通常需要更大的值。

切分发生在标签编译前，每段继承导演说明和说话方式，分别生成闭合标签，因此不会切断 `<whisper>…</whisper>`。生成音频顺序拼接成当前记录，原台词与字幕不被截断。分句会增加请求次数和重复指导文本，不能承诺固定的时延或费用改善；用当前声音对照试听后决定上限。

## 参考音与 Fish 零样本输入

有绑定的服务音色 ID 时优先发送 `reference_id`。没有 ID 时，Fish 适配器通过 MessagePack 上传当前参考录音的原始字节与准确转写；不会把48 kHz参考录音预先降为16 kHz。Fish WAV 输出默认44.1 kHz，不能把参考录音的48 kHz误写成 WAV 输出采样率保证。

参考录音须获得使用授权，尽量单人、干净、与角色说话场合相符；文本应匹配实际录音。想做自然口语，就优先选自然口语参考。可给同一说话者建立日常、轻声、活泼等多条参考音色，再由角色卡选择。当前版本不按台词关键词自动换情绪参考包。

实践文档里的15～25秒情绪拼包和350 ms间隔可作为试验参数，不能替代对实际对齐和音质的检查。AudioSR 高频补全是另一个离线参考音处理步骤；本版不自动安装或执行。它会估计缺失高频，不是还原已丢失的信息；STFT 高频替换及最终全局峰值归一化也不能保证低频逐样本“100% 零损”。保留原件，用同响度试听和频谱对照选择结果。

不在代码或文档中固定“参考音免费”“只按某一字段计费”等未验证承诺，费用以所用 Fish 服务当前账单规则为准。模型权重、服务与声音授权独立于声织许可证。
